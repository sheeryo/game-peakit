# Хотон: Дело о пропавшей капсуле

## Идея и концепция
Видеоигра с участием маскотов фестиваля «Хотон», которая позволяет познакомиться с персонажами в интерактивном формате.
Сами маскоты в игре являются НПС-квестодателями, которые будут просить игрока пройти уникальные уровни, связанные по тематике с самим персонажем.

## Игровой процесс
Игроку предстоит встретиться со всеми маскотами фестиваля «Хотон» и пройти их миссии.
У каждой миссии свой стиль игры: головоломка, викторина, ритм-игра, симулятор.
Целью игрока является пройти все миссии и получить хорошую концовку (в противном случае получится плохая концовка).

## Управление
| Клавиша | Действие |
|---|---|
| Стрелки / WASD | ходить |
| Enter | говорить, взаимодействие |
| Tab | детективный блокнот |
| Esc | меню, пропустить |
| Удержание R | рестарт |
